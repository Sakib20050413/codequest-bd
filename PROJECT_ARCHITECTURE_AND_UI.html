Relational Database Architecture (ERD & Schema)

ফুল-স্ট্যাক ওয়েব অ্যাপ্লিকেশনের জন্য নরমালাইজড রিলেশনাল ডেটাবেজ মডেল। এটি SQLite ও PostgreSQL উভয়ের জন্য সরাসরি প্রযোজ্য।

Core Entity Schema Definitions

Table Name Field Name Data Type Key / Constraint Description
courses slug VARCHAR(60) UNIQUE Canonical URL identifier (e.g., html-core, python-core).
lessons course_id INTEGER FK -> courses.id Cascading foreign key mapping lesson to its parent curriculum.
lessons tests_json JSON / TEXT NOT NULL Structured regex rules and assertion matchers executed by client runner.
user_lesson_progress user_id, lesson_id INTEGER UNIQUE(user, lesson) Tracks completion state, earned XP, and submission timestamps.
arcade_games domain VARCHAR(50) INDEXED Categorizes 108 games across 10 domains (3D WebGL, 2D Canvas, SQL, CTF).

Step 3: Client-Side AST Test Runner (web_runner.js)

সার্ভারে কোড না পাঠিয়ে ব্রাউজারেই নিরাপদ স্যান্ডবক্সে কোড পার্স ও অ্যাসারশন যাচাই করা:

// Client-Side AST evaluation via DOMParser
function verifySolution(userHtml, testRules) {
  const doc = new DOMParser().parseFromString(userHtml, 'text/html');
  return testRules.map(rule => {
    const el = doc.querySelector(rule.selector);
    const pass = el && (!rule.text || el.textContent.includes(rule.text));
    return { title: rule.title, pass: !!pass };
  });
}
