About CodeQuest — Interactive Programming Tutorial & Coding Game Platform

CodeQuest is a full-stack web application developed for CSE 324 (Web Technologies Sessional) at Bangladesh Army International University of Science and Technology (BAIUST). The objective of this project is to help students learn programming languages quickly through short lessons, 1-minute concept videos, an online multi-language code compiler, and interactive coding games.

Key Features Implemented in This Project

Feature Description
1. Short Lessons & 1-Minute Video Guides Instead of long 10-hour video courses, each lesson provides a concise reading guide and a 1-minute chaptered concept video so students can quickly understand the topic before writing code.
2. 16 Programming Languages & Databases Covers HTML5, CSS3, JavaScript, React, Python 3, Django, PHP, C, C++, Java, Rust, SQL, MySQL, PostgreSQL, MongoDB, and AI/Machine Learning basics.
3. Online Multi-Language Compiler Students can write and execute code or CLI commands directly in the browser via the backend execution endpoint (/api/terminal/execute/).
4. Learn by Playing Coding Games Each language includes interactive visual coding games where running code in the terminal controls the game state (bridge alignment, rover pathfinding, database tables, and circuit nodes).
5. Dual Streak System & Open Contests Tracks both Course Streak (daily lesson completion) and Game Streak (daily coding game completion), alongside open coding contests (IUPC, Hackathon, Game Contest, SQL Contest).

Full-Stack Architecture & PHP Database Connection

This project integrates HTML5, CSS3, and JavaScript on the frontend with Python Django on the backend, an SQL relational database, and a standalone PHP mysqli database module located in php_sessional_crud/db.php and php_sessional_crud/index.php.

php_sessional_crud/db.php — PHP 8 MySQLi Database Connection & Prepared Statement Example 
<?php
$host = '127.0.0.1';
$user = 'root';
$pass = '';
$db   = 'codequest_sessional_db';

$conn = new mysqli($host, $user, $pass, $db);
if ($conn->connect_error) {
    die("Database connection failed: " . $conn->connect_error);
}
$conn->set_charset("utf8mb4");

// Prepared statement query for student progress records
$stmt = $conn->prepare("SELECT student_id, full_name, department, xp FROM students ORDER BY xp DESC");
$stmt->execute();
$result = $stmt->get_result();
?>
