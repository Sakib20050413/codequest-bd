Mission & Architecture

About CodeQuest BD

CodeQuest BD is built on a direct premise: developers learn by writing and understanding code, not by passively watching video lectures.

1. Focused 3–7 Minute Micro-Lessons

Every lesson isolates one conceptual mental model and avoids artificial filler. You study the explanation, inspect a practical reference example, and immediately write code to satisfy automated test criteria.

2. Client-Side Sandboxed Security Architecture

To eliminate server execution risk and latency, all interactive code runs securely in the user's browser. Web layouts execute in sandboxed iframes (sandbox="allow-scripts"), Python runs via WebAssembly (Pyodide), and SQL queries run inside a browser-based relational engine (sql.js).

3. Local-First Progress & Cloud Synchronization

Learners can immediately start solving exercises without creating an account. Progress is stored locally in the browser's localStorage. When you register or sign in, all completed lessons and earned XP are automatically synced to your persistent cloud profile.

4. Restrained Aesthetics & Accessibility (WCAG 2.2 AA)

We avoid flashy cartoon distractions and exaggerated gamification. CodeQuest adheres to strict contrast guidelines across both light and dark themes, includes visible focus indicators, supports reduced motion preferences, and optimizes for screen reader landmarks.
