CSE 324 Project Architecture (Frontend, Django Backend, SQL Database & PHP Connection)

Summary of the 4 technical layers implemented in this project for CSE 324 Web Technologies Sessional.

System Layer Technologies Used Project Files & Implementation
1. Frontend UI HTML5, CSS3, JavaScript (ES6+) Responsive templates in templates/, styles in static/css/codequest.css, and canvas video/game script in static/js/micro_video_and_game_engine.js.
2. Backend Server Python 3.12, Django 5 (MVT) URL routing, authentication, course/game views in learn/views.py, and multi-language execution API in learn/polyglot_engine.py.
3. Relational & NoSQL Database SQLite3 / MySQL / PostgreSQL & MongoDB Relational schema in learn/models.py (Courses, Lessons, Games, Contests, Certificates) plus live SQL and mongosh query execution.
4. PHP Database Connector PHP 8 (mysqli & PDO Prepared Statements) Standalone PHP-to-MySQL CRUD module in php_sessional_crud/db.php and php_sessional_crud/index.php, plus live PHP-SQL execution in the compiler.
