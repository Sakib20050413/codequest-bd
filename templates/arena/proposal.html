1. Executive Summary & Problem Statement

Undergraduate computer science students frequently face a disconnect between theoretical programming syntax and spatial, computational intuition. Traditional online judges (e.g., Codeforces, LeetCode) present abstract text-in/text-out interfaces that fail to visually engage early-tier learners. Simultaneously, web development courses require students to bridge complex frontend DOM trees with backend relational databases.

CodeQuest BD addresses this pedagogical bottleneck by synthesizing four specialized interactive engines into a unified web portal: (1) a 2D Cyber Rover Grid Maze for procedural loop mastery, (2) a live CSS/DOM split-screen sandbox for web layout visualization, (3) a Piston-backed multi-language compiler sandbox with offline lab fallback, and (4) a 60-second Bug-Hunter Blitz mode for continuous quiz readiness. Additionally, a dedicated procedural PHP + MySQLi CRUD module directly satisfies all CSE 324 Evaluation iv requirements.
